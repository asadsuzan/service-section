The **Services Section** plugin provides a responsive, customizable Gutenberg block to highlight your services with modern card designs.  
Built for freelancers, agencies, and businesses, this plugin lets you present your services in a professional and engaging way.

### Key Features – Free Version
- **Multiple Layouts & Themes:** Choose from different card styles to match your brand.
- **Responsive Design:** Looks great on desktop, tablet, and mobile.
- **Block Editor Controls:** Customize text, colors, spacing, and icons easily.
- **Lightweight & Optimized:** Minimal code, maximum performance.
- **Translation Ready:** Works with multilingual sites.

== Installation ==
This section describes how to install the plugin and get it working.

1. Upload the `services-section` folder to the `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Search for **Services Section** in the block editor and add it to your page.

== Frequently Asked Questions ==

= Does it work with all themes? =
Yes, it works with any modern WordPress theme, especially block-based themes.
